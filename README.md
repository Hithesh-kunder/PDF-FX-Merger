# PDF-FX Merger

A web application that allows users to upload and merge PDF files into a single PDF document using JavaScript and Node.js.

## Features

- Upload PDF files through a web interface.
- Merge multiple PDF files into one document.
- Download the merged PDF.
- Simple and user-friendly interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Multer
- pdf-merger-js


## Installation and Setup

1. Clone this repository:

```bash
git clone https://github.com/Hithesh-kunder/PDF-FX-Merger.git
```

2. Navigate to the project folder:

```bash
cd PDF-FX-Merger
```

3. Install the dependencies:

```bash
npm install
```

4. Start the server:

```bash
node server.js
```

5. Open your browser and visit:

```text
http://localhost:3000
```

## Purpose

This project was developed to practice JavaScript, Node.js, Express.js, file uploads, and backend development.
